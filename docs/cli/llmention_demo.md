# llmention demo

Try llmention without API keys

## Usage

```
llmention demo
```

## Examples

```
llmention demo
llmention demo --keep ./llmention-demo
llmention demo --json
```

## Flags

- `--keep` Save the demo project and its history in this folder

## Output

Shows text you can read in your terminal.

Use --json to get JSON for scripts and other programs.

## Related commands

- llmention quick
- llmention init
