# llmention suites validate

Check a suite and show its prompts

## Usage

```
llmention suites validate <suite-id-or-file>
```

## Examples

```
llmention suites validate prompts
llmention suites validate ./examples/research/factoid.yaml
```

## Output

Shows text you can read in your terminal.

Use --json to get JSON for scripts and other programs.

## Related commands

- llmention suites list
